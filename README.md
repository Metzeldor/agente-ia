# Agente de IA: proyecto de aprendizaje

Proyecto personal para aprender a construir un agente de IA completo, desde el servidor hasta la interfaz de chat, usando herramientas modernas y planes gratuitos.

Autor: Andrés Tejada

## Qué es

Un agente de IA con el que se puede conversar desde el navegador, que recuerda las conversaciones y puede usar herramientas sencillas. Es un proyecto didáctico: el objetivo principal es aprender, y el resultado final es una pieza para mi portafolio.

## Stack tecnológico

- Lenguaje: TypeScript en frontend y backend.
- Backend: Node.js con Hono.
- Base de datos: PostgreSQL con Drizzle ORM.
- Entorno: Docker (opcional según los recursos del equipo).
- Autenticación: Better Auth.
- Frontend: React con TanStack Query y Zustand.
- Estilos: shadcn/ui y Tailwind.
- Modelo de IA: API con plan gratuito (Groq o Google Gemini).

- backend: servidor, rutas, lógica del agente y base de datos.

- docs: notas y plan de trabajo.

## Cómo ejecutarlo

Esta sección se completará a medida que avance el proyecto. Por ahora el plan es:

1. Clonar el repositorio.
2. Copiar el archivo de variables de entorno de ejemplo y añadir tu propia clave de API.
3. Instalar las dependencias en backend y frontend.
4. Iniciar el servidor y la interfaz en modo desarrollo.

## Variables de entorno

La clave de la API del modelo se guarda en un archivo de variables de entorno que nunca se sube al repositorio.
